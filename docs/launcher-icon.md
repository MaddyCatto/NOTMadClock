# Иконка MadClock

Использован оригинальный файл **MadClock Neon Alarm Monogram.png** из архива
пользователя: 1254×1254, SHA-256
`2fec6ea5832eb171d2ab87df9c3b21a0b5fc4bdcc1944c9a1aa9fc14a00879e7`.

[Исходный PNG](../app/src/main/res/drawable-nodpi/ic_launcher_artwork.png) сохранён
побайтно. Изображение не перерисовывалось, фон не удалялся, цвета и геометрия
не менялись. Один nodpi PNG используется Android во всех плотностях через
scalable bitmap drawable; изменённые растровые копии не создаются. PNG crunch
для release выключен, проверка готового APK сравнивает SHA-256 самого PNG.

Основной manifest ссылается на `mipmap/ic_launcher` и `mipmap/ic_launcher_round`.
Оба — adaptive icon; minSdk приложения 26, поэтому отдельный pre-26 fallback
не нужен. Передний слой — исходное изображение с равномерным InsetDrawable
12,5% с каждой стороны. На стандартном слое 108 dp это оставляет bitmap 81 dp;
видимый знак помещается внутри безопасного круга диаметром 66 dp. Цвет нижнего
слоя `#180330` взят из углового пикселя оригинала. Форму маски выбирает launcher.

Проверки API 28/36 подтверждают тип adaptive drawable и привязку manifest.
Native Android renderer на модели API 28 проверяет круг, скруглённый квадрат
и squircle: все яркие пиксели знака остаются внутри безопасного круга и совпадают
с немаскированным слоем, то есть знак не обрезается. Рендеры `launcher-*.png`
публикуются вместе с экранами в артефакте CI. Это не снимки физического OnePlus.

Lint предупреждает о квадратном непрозрачном исходном PNG (`IconLauncherShape`)
и об отсутствии optional monochrome-варианта у двух adaptive resources.
Предупреждения не скрываются: исходный квадрат обрабатывается реальной маской
и отступами; monochrome-вариант изменил бы заданный цветной дизайн и не добавлялся.
Отрисовку конкретного launcher/OxygenOS нужно проверить на устройстве.

MadClock Audio не менялся: у него нет launcher Activity/alias. Его прежние
служебный значок и уведомление Foreground Service сохранены.
