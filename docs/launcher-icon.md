# Иконка MadClock и MadClock Audio

Фиолетовая плашка вырезана из предоставленного `icon.png` размером
1254 × 1254. SHA-256 исходника
`566901bf4fde3f1fd9d5928e5e1744f294ca9394336d4dccb28741256465d2df`.

Белый фон удалён заливкой альфа-канала от внешнего угла с допуском 38%.
Маска сужена на один пиксель, чтобы убрать светлую кайму. Затем из исходного
холста выбрана область 1156 × 1156 со смещением (49, 49). Каждый видимый
пиксель совпадает по RGB с исходником.

[Обрезанный ресурс PNG](../shared/src/main/res/drawable-nodpi/ic_launcher_artwork.png)
имеет SHA-256 `c16072358e2732216fcc2e9207f9bb24da62d8ec5158a43b117c66a98e72862a`.
Этот хеш проверяется в обоих собранных APK.

Обычные и круглые иконки обоих пакетов используют один adaptive icon.
Отступы по 15% сохраняют монограмму внутри безопасного круга диаметром
66 dp. За прозрачными углами подложка `#1C023D` из исходной плашки.
Robolectric с нативной графикой проверяет круг, скруглённый квадрат и
сквиркл. Рендеры `launcher-*.png` публикуются в артефакте CI.

MadClock Audio доступен в списке приложений. Его экран показывает назначение
компонента и исключён из Recent Tasks. Служебное уведомление ведёт в MadClock.
