# Иконка MadClock и MadClock Audio

Оба приложения используют исходный `icon.png` размером 1254 × 1254.
[Общий ресурс PNG](../shared/src/main/res/drawable-nodpi/ic_launcher_artwork.png)
сохранён побайтно. SHA-256
`566901bf4fde3f1fd9d5928e5e1744f294ca9394336d4dccb28741256465d2df`.

Manifest каждого пакета ссылается на `mipmap/ic_launcher` и
`mipmap/ic_launcher_round`. Оба adaptive icon используют одну растровую копию
без изменения цветов и композиции. Отступ в 29% с каждой стороны стандартного
слоя 108 dp оставляет PNG шириной 45,36 dp. Его диагональ поместится в круг
безопасной области диаметром 66 dp. Нижний слой повторяет цвет верхнего левого
угла PNG. Форму маски задаёт launcher.

Оригинальные байты проверяются в обоих собранных APK. Robolectric с нативной
графикой проверяет круг, скруглённый квадрат и сквиркл на API 28. Рендеры
`launcher-*.png` публикуются вместе с экранами в артефакте CI. Отображение в
launcher OxygenOS проверяется на устройстве.

MadClock Audio доступен в списке приложений. Его экран показывает назначение
компонента и исключён из Recent Tasks. Служебное уведомление ведёт в MadClock.
