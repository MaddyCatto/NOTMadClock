# Воспроизведение независимо от интерфейса

Основной MadClock больше не содержит аудиосервиса и recovery после Recent Tasks.
Звук воспроизводит только отдельный пакет MadClock Audio. Никакого polling или
постоянной фоновой работы между будильниками нет.

[Расписание, независимое аудио, системные ограничения и сценарии проверки](alarms.md).
