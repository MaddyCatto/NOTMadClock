# Прежняя архитектура восстановления

Начиная с версии 0.2.0 основной MadClock не содержит аудиосервиса,
MediaPlayer, playback WakeLock и восстановления звука после Recent Tasks.
Старые recovery-команды не исполняются; их PendingIntent отменяются при миграции.

Актуальная архитектура и проверка двух альтернативных режимов описаны в
[экспериментальных звуковых режимах](experimental-audio.md).
