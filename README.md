# MadClock

До 10 независимых будильников с тёмным интерфейсом Deep Purple и выключением
по одному общему штрихкоду. У каждого будильника своё время, повторение
«Ежедневно» / «Однократно», локальная песня и громкость 1–100%.

Главный экран содержит карточки с мгновенными переключателями и кнопку «+».
Нажатие на карточку открывает редактирование. Регистрация штрихкода, разрешения,
тест выбранной песни и информация о приложении находятся в меню ⋮.
Когда сигнал активен, появляется кнопка сканирования для его выключения.

## Два APK, один механизм звука

- **MadClock** (`com.madclock.app`): интерфейс, настройки, AlarmManager,
  офлайн-сканер и команды помощнику. Собственного воспроизведения, звукового
  Foreground Service, playback WakeLock или перезапусков после Recent Tasks нет.
- **MadClock Audio** (`com.madclock.audio`): единственный проигрыватель. Повторяет
  песню в отдельном mediaPlayback Foreground Service, контролирует громкость
  только во время сигнала. У него нет launcher-иконки или карточки воспроизведения
  в Recent Tasks. Служебное уведомление Android остаётся.

Экспериментальный режим звуковых уведомлений удалён. Между установкой будильника
и срабатыванием оба приложения бездействуют: нет polling или постоянно работающих
сервисов. Каждый включённый будильник имеет собственное точное системное событие.

Однократный будильник после срабатывания выключает свой переключатель; музыка
продолжается до правильного штрихкода. Пересекающиеся события не прерывают
текущую песню и не создают второй поток. Следующие ежедневные события сохраняются.
Редактирование, удаление или выключение карточки меняет её будущее расписание,
а уже активный сигнал останавливается только сканированием.

## Установка

1. Скачайте артефакт **MadClock-1.0-debug-pair** из успешного GitHub Actions.
   Он содержит `MadClock-debug.apk` и `MadClock-Audio-debug.apk` с одной подписью.
2. Установите Audio, затем основной MadClock. Не смешивайте APK разных сборок.
3. В меню ⋮ зарегистрируйте штрихкод. В «Проверка разрешений» разрешите камеру,
   точные будильники и уведомления MadClock Audio. Настройка помощника открывается
   оттуда, launcher-иконка не нужна. При необходимости разрешите фоновую работу
   **MadClock Audio** в OxygenOS.
4. Добавьте будильник, выберите локальную песню и сохраните. Через «Тест звука»
   можно немедленно проверить песню конкретной карточки без изменения расписания.
   Для остановки теста тоже нужен зарегистрированный штрихкод.

```sh
adb install -r MadClock-Audio-debug.apk
adb install -r MadClock-debug.apk
```

Обновление с сохранением данных требует прежнего ключа подписи. Debug-ключи
разных CI-запусков могут различаться: Android отклонит такое обновление.
Не удаляйте установленную версию, если нужно сохранить настройки.
При совместимой подписи прежние песня, время, громкость и код мигрируют в одну
ежедневную карточку; уже активный сеанс помощника сохраняет свой идентификатор.

## Сборка и проверки

Gradle 8.13, AGP 8.13.2, Kotlin 2.2.20, SDK 36. Для Android 16 в Robolectric
нужна Java 21; байткод APK остаётся Java 17.

```sh
gradle :app:assembleDebug :audio:assembleDebug :app:testDebugUnitTest :audio:testDebugUnitTest :app:lintDebug :audio:lintDebug --no-daemon --max-workers=4
python3 scripts/check_apks.py
```

Результат: `app/build/outputs/apk/debug/app-debug.apk` и
`audio/build/outputs/apk/debug/audio-debug.apk`. Скрипт проверяет подписи,
раздельность пакетов, защищённый IPC, отсутствие сетевых разрешений и собственного
звукового механизма в основном APK. CI публикует комплект APK и отдельный
артефакт **MadClock-Deep-Purple-screens** с рендерами настоящих Android View.

Проверки расписаний и интерфейса выполняются на моделях API 28 и 36; отдельно
проверяется сервис Audio. Это не заменяет испытания звука и энергосбережения на
устройстве. Пользователь подтвердил устойчивость прежнего режима B на OnePlus
Pad 3; новая версия с десятью карточками требует повторного испытания.
Force Stop, системная остановка сервисов, отзыв разрешений и ограничения
производителя имеют приоритет; обхода этих действий нет.
